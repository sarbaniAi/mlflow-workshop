MLflow Projects & deployment

Packaging code, not just the model

MLproject

 

name: wine-classifier

conda_env: conda.yaml

 

entry_points:

main:

parameters:

n_estimators: {type: int}

command: "python train.py {n_estimators}"

 

# run it, anywhere, reproducibly

$ mlflow run . -P n_estimators=300

An MLproject file captures the entry point, parameters and environment — so "how do I even run this?" has one answer, not five READMEs

The environment (conda.yaml or requirements.txt) travels with the code — the same run works on your laptop, a teammate's, or a CI runner

Deployment, the simplest version: mlflow models serve -m models:/name@champion turns a registered model into a local REST endpoint in one line
