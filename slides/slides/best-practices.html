Best practices that save you later

Log a signature and input example on every model — not just the ones you plan to serve

Serve by alias, never a hardcoded version number — promotion becomes a metadata change, not a redeploy

Tag runs like commit messages — owner, dataset version, git commit — future-you will search by tag

Don't log raw training data as an artifact — log a small sample or a versioned pointer instead

Pin dependencies explicitly — an unpinned conda.yaml breaks silently, months later

Wire logging into CI/CD — tracking only the runs you remember to log manually isn't tracking
