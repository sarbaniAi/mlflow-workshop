MLflow Evaluation

Scoring quality, not just accuracy

Classic ML

One call — mlflow.evaluate() — computes accuracy, F1, ROC-AUC or RMSE, MAE, R² automatically, plus a confusion matrix and feature-importance plot.

Custom metrics

Define any business metric as a Python function — cost-weighted error, fairness gap, domain-specific scores — and log it alongside the standard ones.

The same framework extends to LLM outputs — relevance, faithfulness, toxicity — including LLM-as-judge metrics. Where the field is heading next.
