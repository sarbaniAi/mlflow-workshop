What is MLflow?

An open-source platform to manage the end-to-end machine learning lifecycle.

Framework-agnostic

scikit-learn, PyTorch, TensorFlow, XGBoost, Spark, and LLM frameworks

Runs anywhere

Laptop, on-prem server, or a managed cloud service

Multi-language

Python, R and Java APIs, plus a REST API and CLI

Emphasize: MLflow is not tied to any one company or cloud — it's a CNCF-adjacent open standard that most teams already have access to today via pip install.
